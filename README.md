# Listner

Cross-platform voice dictation and transcription desktop application powered by local Whisper.cpp and cloud transcription providers.

## Key Features

- **Offline Transcription**: Runs private, on-device Whisper models via whisper.cpp.
- **Cloud Providers**: Bring your own keys (BYOK) for Groq, OpenAI Whisper, or custom OpenAI-compatible endpoints.
- **Multilingual & Translation**: Real-time translation to Indian and international languages via Sarvam AI.
- **Global Hotkey & Wayland Support**: Toggle or push-to-talk dictation across Windows and Linux (including Niri and Hyprland compositors).
- **Movable Indicator**: Floating dictation overlay that remembers its screen position.

## Getting Started

### Prerequisites

- Node.js (v18+)
- pnpm (v9+)

### Installation & Run

```bash
pnpm install
pnpm start
```
