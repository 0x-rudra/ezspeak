⚡ Linux Wayland Compositor Setup (Niri, Hyprland, Sway) IPC Port 49152

On Wayland, background global shortcuts are controlled by your compositor. You can bind any compositor key to trigger dictation via Listner's local IPC:

curl -s http://127.0.0.1:49152/toggle

• Niri (~/.config/niri/config.kdl):
  Keybind: Ctrl+Alt+Space { spawn "curl" "-s" "http://127.0.0.1:49152/toggle"; }
  Floating popup rule: window-rule { match title=r#"^(listner|ezspeak)-indicator$"#; open-floating true; open-focused false; }
• Hyprland (~/.config/hypr/hyprland.conf): bind = CTRL ALT, SPACE, exec, curl -s http://127.0.0.1:49152/toggle
